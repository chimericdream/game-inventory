# The Shelf: design reference

Static HTML mockups from the isolated redesign exercise. Open `source/index.html` in a browser to
browse every screen and state. `README.md` describes the direction; `CRITIQUE.md` logs the design
review. The PNG screenshots are not committed (about 10 MB); regenerate them by opening the pages at
1440, 820 and 390 px wide.

These files are a visual reference only. `docs/REDESIGN_BUILD_PLAN.md` is the source of truth where the
two differ. The generated SVG cover art in `source/data.js` is mockup-only, except for the static shelf
on the sign-in page.
